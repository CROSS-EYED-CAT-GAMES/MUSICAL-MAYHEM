Démarrage rapide
  1. Ouvrez SCREEN sur la TV : le QR code et le code à 4 chiffres s'affichent.
  2. Ouvrez HOST sur votre ordinateur, entrez la clé animateur affichée dans le terminal.
  3. Les joueurs scannent le QR code avec leur téléphone et choisissent leur équipe.
  4. Depuis HOST, configurez les épreuves puis cliquez DÉMARRER LA SÉLECTION : c'est parti.

Astuce test solo : bouton 🧪 DEMO dans le cockpit Host pour simuler une partie complète.
